# Campaña Tip del Martes

Este repositorio contiene los entregables para la campaña "Tip del martes" de Craftdigit:

- `content/` artículo interactivo con prompt copiable.
- `design/` maqueta HTML5 + CSS3 responsiva (Flexbox) que usa la paleta azul plomo y verde neón.
- `social/` mensaje optimizado para WhatsApp.
- `assets/` imagen usada como hero.

Flujo de trabajo:
1. Crear rama `campaña-tip-martes`.
2. Incorporar contenido y diseño.
3. Revisar y hacer merge limpio en `main` para actualizar GitHub Pages.
